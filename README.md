# Simpan-App (Sistem Informasi Kearsipan)

`simpan-app` adalah aplikasi berbasis web yang dirancang untuk mengelola arsip digital secara terstruktur, aman, dan efisien. Proyek ini dibangun menggunakan **Laravel** dan dikemas menggunakan **Docker** untuk memastikan kemudahan proses *deployment* dan lingkungan pengembangan yang konsisten.

---

## 🚀 Tech Stack
* **Framework:** Laravel
* **Database:** MySQL 8.0
* **Web Server:** Nginx
* **Containerization:** Docker & Docker Compose

---

## 📋 Prerequisites
Sebelum menjalankan aplikasi ini, pastikan komputer/laptopmu sudah terinstal perangkat lunak berikut:
* [Git](https://git-scm.com/)
* [Docker](https://www.docs.docker.com/get-docker/)
* [Docker Compose](https://docs.docker.com/compose/)
